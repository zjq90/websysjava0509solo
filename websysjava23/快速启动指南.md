# 医院住院管理系统 - 快速启动指南

## 🚀 快速启动

### 方式一：使用启动脚本（推荐）

#### 1. 启动后端服务
双击运行 `启动后端.bat` 文件
- 自动检查Java和Maven环境
- 自动编译并启动Spring Boot服务
- 后端地址：http://localhost:8080

#### 2. 启动前端服务
双击运行 `启动前端.bat` 文件
- 自动检查Node.js和npm环境
- 自动安装依赖（首次运行）
- 自动启动Vue开发服务器
- 前端地址：http://localhost:8081

---

### 方式二：命令行启动

#### 后端启动步骤
```bash
# 进入项目根目录
cd websysjava23

# 编译项目
mvn clean compile

# 启动Spring Boot服务
mvn spring-boot:run
```

#### 前端启动步骤
```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run serve
```

## 📊 H2数据库配置

在H2控制台登录页面输入以下信息：

- **JDBC URL**: `jdbc:h2:mem:hospitaldb`
- **用户名**: `sa`
- **密码**: （留空）
- **驱动类**: `org.h2.Driver`

> 注意：H2是内存数据库，重启后端服务后数据会重置。系统启动时会自动初始化测试数据。

## 🔧 常见问题解决

### 问题1：Maven命令找不到
**解决**：
1. 下载并安装Maven：https://maven.apache.org/download.cgi
2. 配置Maven环境变量：
   - 新建系统变量 `MAVEN_HOME`，值为Maven安装目录
   - 在Path中添加 `%MAVEN_HOME%\bin`
3. 重启命令行窗口

### 问题2：端口被占用
**解决**：
- 修改 `src/main/resources/application.properties` 中的 `server.port`
- 或修改 `frontend/vue.config.js` 中的 `devServer.port`

### 问题3：前端无法连接后端
**解决**：
1. 确认后端服务已启动
2. 检查 `frontend/src/main.js` 中的 `axios.defaults.baseURL` 是否正确
3. 后端默认地址：`http://localhost:8080/api`

### 问题4：依赖安装失败
**解决**：
```bash
# 清除缓存重新安装
cd frontend
rm -rf node_modules package-lock.json
npm install
```

### 问题5：编译错误
**解决**：
1. 确认Java版本为1.8或更高
2. 检查Maven本地仓库是否完整
3. 尝试清理并重新编译：`mvn clean install`
