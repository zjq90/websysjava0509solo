# 图标文件说明

此目录需要放置以下PNG图标文件（尺寸建议81x81或更小）：

## 需要的图标文件

### 首页
- `home.png` - 首页图标（未选中状态）
- `home-active.png` - 首页图标（选中状态）

### 库存
- `inventory.png` - 库存图标（未选中状态）
- `inventory-active.png` - 库存图标（选中状态）

### 扫码
- `scan.png` - 扫码图标（未选中状态）
- `scan-active.png` - 扫码图标（选中状态）

### 消息
- `notification.png` - 消息图标（未选中状态）
- `notification-active.png` - 消息图标（选中状态）

### 客户
- `customer.png` - 客户图标（未选中状态）
- `customer-active.png` - 客户图标（选中状态）

## 图标要求

1. **格式**：PNG（支持透明背景）
2. **尺寸**：建议 81x81 像素
3. **颜色**：
   - 未选中状态：灰色（建议 #999999）
   - 选中状态：主题蓝色（建议 #2979FF）

## 获取图标方式

### 方式1：使用在线图标库
- 阿里巴巴矢量图标库：https://www.iconfont.cn/
- 下载PNG格式图标

### 方式2：使用emoji截图
可以使用以下emoji作为参考，截图后保存为PNG：
- 首页：🏠
- 库存：📦
- 扫码：📷
- 消息：🔔
- 客户：👥

### 方式3：使用设计工具创建
使用Figma、Sketch、Photoshop等设计工具创建图标

## 临时解决方案

如果暂时没有图标，可以修改 `pages.json` 中的 tabBar 配置，
暂时移除图标引用（仅保留文字），但这在某些平台可能不被支持。

推荐方案：使用简单的emoji截图作为临时图标。
