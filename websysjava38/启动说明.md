# 影楼管理系统启动指南

## 一、启动前准备

### 1.1 检查环境
确保已安装以下软件：
- **JDK 8** 或更高版本
- **Maven** 3.6+
- **Node.js** 16+
- **npm** 8+

### 1.2 验证命令
打开命令行窗口，依次执行以下命令验证环境：
```bash
java -version
mvn -version
node -version
npm -version
```

如果都能正常显示版本号，说明环境配置正确。

---

## 二、启动后端服务

### 2.1 Windows 启动方式

**方式一：使用命令行**
1. 打开 CMD 或 PowerShell
2. 进入项目根目录：
   ```bash
   cd d:\Aijava\javaproject\260509\solocodeJava\v38\websysjava38
   ```
3. 编译并启动：
   ```bash
   mvn clean spring-boot:run
   ```

**方式二：使用 IDE**
1. 使用 IntelliJ IDEA 或 Eclipse 打开项目
2. 找到 `PhotoStudioApplication.java`
3. 右键点击，选择 "Run" 或 "Debug"

### 2.2 验证后端启动成功

看到类似以下日志说明启动成功：
```
Started PhotoStudioApplication in XX seconds
Tomcat started on port(s): 8080 (http)
```

**访问验证地址：**
- Swagger API 文档：http://localhost:8080/api/swagger-ui.html
- H2 数据库控制台：http://localhost:8080/api/h2-console
  - JDBC URL: `jdbc:h2:file:./data/photostudio`
  - 用户名: `sa`
  - 密码: （留空）

## 五、常见问题

### 5.1 后端启动失败

**问题：端口 8080 被占用**
```bash
# Windows 查看端口占用
netstat -ano | findstr 8080

# 关闭占用进程（替换 PID 为实际进程号）
taskkill /F /PID 进程号
```

**问题：Maven 下载依赖慢**
- 配置 Maven 阿里云镜像：在 `settings.xml` 中添加镜像
- 或者使用国内 Maven 仓库

### 5.2 前端启动失败

**问题：npm install 失败**
```bash
# 清理缓存后重试
npm cache clean --force
rm -rf node_modules
npm install
```

**问题：跨域问题**
- 确保后端已启动
- 检查 `vite.config.js` 中的代理配置是否正确
- 代理目标应为 `http://localhost:8080/api`

### 5.3 数据库问题

**问题：H2 控制台无法登录**
- 确认 JDBC URL 正确：`jdbc:h2:file:./data/photostudio`
- 确认用户名为 `sa`，密码为空
- 如果数据损坏，删除 `data` 目录后重新启动
