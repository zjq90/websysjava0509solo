# 共享单车系统测试指南

## 测试环境准备

### 1. 后端环境准备

#### 1.1 安装JDK
- 下载并安装 JDK 11 或更高版本
- 配置环境变量 `JAVA_HOME`
- 验证安装：`java -version`

#### 1.2 安装Maven
- 下载并安装 Maven 3.6+
- 配置环境变量 `MAVEN_HOME`
- 验证安装：`mvn -version`

#### 1.3 安装Redis (可选)
- 下载并安装 Redis
- 启动 Redis 服务
- 默认端口：6379

> **注意**：如果没有Redis，系统也可以正常运行，缓存功能会自动降级

### 2. 前端环境准备

#### 2.1 安装Node.js
- 下载并安装 Node.js 14+
- 验证安装：`node -v` 和 `npm -v`

#### 2.2 安装HBuilderX
- 下载 HBuilderX（推荐用于UniApp开发）
- 或使用 VS Code + 微信开发者工具

## 后端启动测试

### 1. 编译项目

```bash
cd backend
mvn clean compile
```

### 2. 运行项目

方式一：使用Maven运行
```bash
mvn spring-boot:run
```

方式二：打包后运行
```bash
mvn clean package -DskipTests
java -jar target/bike-sharing-backend-1.0.0.jar
```

### 3. 验证启动成功

启动成功后，控制台会显示：
```
========================================
  共享单车系统后端服务启动成功!
  接口文档: http://localhost:8080/api/swagger-ui.html
  H2控制台: http://localhost:8080/api/h2-console
========================================
```

### 4. 访问测试页面

| 页面 | 地址 | 说明 |
|------|------|------|
| Swagger API文档 | http://localhost:8080/api/swagger-ui.html | 接口测试工具 |
| H2数据库控制台 | http://localhost:8080/api/h2-console | 数据库管理 |

#### H2控制台配置
- JDBC URL: `jdbc:h2:file:./data/bikedb`
- 用户名: `sa`

## API接口测试

### 使用Swagger测试接口

1. 访问 http://localhost:8080/api/swagger-ui.html
2. 展开各个接口模块
3. 点击 "Try it out" 进行测试

### 1. 用户模块测试

#### 1.1 发送短信验证码
```
POST /api/user/send-sms-code?phone=13800138001
```

#### 1.2 用户注册
```json
POST /api/user/register
{
  "phone": "13800138002",
  "password": "123456",
  "smsCode": "123456",
  "nickname": "测试用户"
}
```

#### 1.3 用户登录
```json
POST /api/user/login
{
  "phone": "13800138001",
  "password": "123456"
}
```

**预期结果**: 返回token和用户信息

#### 1.4 获取用户信息
```
GET /api/user/info
Header: Authorization: Bearer {token}
```

### 2. 车辆模块测试

#### 2.1 获取附近车辆
```
GET /api/bike/nearby?latitude=39.9042&longitude=116.4074&radius=1000
```

#### 2.2 预约车辆
```json
POST /api/bike/reserve
{
  "bikeId": 1
}
```

### 3. 骑行模块测试

#### 3.1 开锁
```json
POST /api/ride/unlock
{
  "bikeId": 1,
  "unlockType": "QRCODE"
}
```

#### 3.2 获取当前骑行信息
```
GET /api/ride/current
```

#### 3.3 锁车
```json
POST /api/ride/lock
{
  "rideRecordId": 1,
  "latitude": 39.9042,
  "longitude": 116.4074
}
```

### 4. 故障上报测试

```json
POST /api/fault/report
{
  "bikeId": 1,
  "faultType": "BRAKE",
  "faultDescription": "刹车失灵",
  "latitude": 39.9042,
  "longitude": 116.4074
}
```

### 5. 优惠券测试

```
GET /api/coupon/my
```

## 常见问题排查

### 1. 后端启动失败

**问题**: 端口被占用
```
Web server failed to start. Port 8080 was already in use.
```
**解决**: 修改 `application.yml` 中的端口号

**问题**: 数据库连接失败
**解决**: 检查 `application.yml` 中的数据库配置，确保路径正确

### 2. 前端无法访问后端

**问题**: 跨域错误
**解决**: 确认后端CORS配置正确，前端API地址配置正确

**问题**: 401未授权
**解决**: 检查token是否正确，登录状态是否有效

### 3. Redis连接失败

**问题**: Redis连接超时
**解决**: 确认Redis服务已启动，或注释掉Redis相关配置（系统支持无Redis运行）
