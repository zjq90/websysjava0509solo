# 宠物问诊保险理赔功能说明

## 📋 功能概述

本系统已完整实现了保险公司API对接和问诊费用直接理赔功能，包含以下核心模块：

1. **保险公司管理** - 支持配置多个保险公司，支持动态管理
2. **理赔预计算** - 提交理赔前自动计算可理赔金额
3. **保单验证** - 验证保单有效性
4. **一键理赔** - 根据问诊ID快速申请理赔
5. **理赔流程管理** - 完整的审核、通过、拒绝、取消、完成流程
6. **理赔状态同步** - 从保险公司同步最新理赔状态

---

## 🏗️ 核心功能

### 1. 保险公司管理

**功能特性：**
- 查询所有保险公司列表
- 查询启用的保险公司
- 新增/编辑/删除保险公司
- 配置理赔比例、免赔额、最高限额
- 配置API接口地址（模拟对接）

**保险公司配置参数：**
| 参数 | 说明 |
|------|------|
| 公司名称 | 保险公司全称 |
| 公司编码 | 唯一标识编码 |
| API地址 | 保险公司接口地址 |
| 默认理赔比例 | 费用报销比例（%） |
| 免赔额 | 最低起赔金额 |
| 最高理赔限额 | 单次理赔最高金额 |
| 保障范围 | 保险覆盖范围说明 |

### 2. 理赔金额计算

**计算公式：**
```
可理赔金额 = 总费用 - 免赔额
理赔金额 = 可理赔金额 × 理赔比例
最终理赔金额 = min(理赔金额, 最高限额)
自付金额 = 总费用 - 最终理赔金额
```

**计算示例：**
- 问诊费用：500元
- 免赔额：100元
- 理赔比例：70%
- 最高限额：5000元

**计算结果：**
- 可理赔金额 = 500 - 100 = 400元
- 理赔金额 = 400 × 70% = 280元
- 自付金额 = 500 - 280 = 220元

### 3. 理赔申请流程

**标准理赔申请：**
```
1. 选择问诊记录
2. 选择保险公司
3. 输入保单号
4. 系统验证保单有效性
5. 预计算理赔金额
6. 提交理赔申请
7. 系统自动对接保险公司
8. 返回理赔结果
```

**一键理赔：**
- 只需提供问诊ID和保单号
- 系统自动获取问诊信息和费用
- 自动选择默认保险公司
- 自动提交到保险公司

### 4. 理赔状态管理

**理赔状态说明：**

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| PENDING | 待审核 | 审核通过、拒绝、取消 |
| APPROVED | 已批准 | 完成支付、取消 |
| REJECTED | 已拒绝 | 无 |
| COMPLETED | 已完成 | 无 |
| CANCELLED | 已取消 | 无 |

### 5. 理赔审核流程

```
提交申请 → 待审核 → 审核通过 → 已批准 → 支付完成 → 已完成
                    ↓
                  拒绝 → 已拒绝
                    ↓
                  取消 → 已取消
```

## 🔌 API接口说明

### 保险公司管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/insurance/companies` | 查询所有保险公司 |

| PUT | `/api/insurance/companies/{id}` | 更新保险公司 |

| GET | `/api/insurance/quote` | 获取保险报价 |

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/insurance/claims` | 创建理赔申请 |

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/insurance/claims` | 查询所有理赔记录 |

| GET | `/api/insurance/claims/status/{status}` | 按状态查询理赔 |

| GET | `/api/insurance/claims/search` | 按宠物名称搜索 |

### 理赔审核处理

| 方法 | 路径 | 说明 |
|------|------|------|
| PUT | `/api/insurance/claims/{id}/review` | 审核理赔申请 |
| PUT | `/api/insurance/claims/{id}/complete` | 完成理赔支付 |
| PUT | `/api/insurance/claims/{id}/reject` | 拒绝理赔 |
| PUT | `/api/insurance/claims/{id}/cancel` | 取消理赔申请 |

## 📝 注意事项

1. **免赔额规则：问诊费用低于免赔额时无法申请理赔
2. **重复理赔**：同一问诊记录只能申请一次有效理赔
3. **状态流转**：已完成/已拒绝/已取消的理赔无法再修改
4. **保单验证**：提交理赔前请确保保单在有效期内
5. **金额限制**：理赔金额不能超过保险公司的最高理赔限额
