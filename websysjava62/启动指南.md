# 宠物问诊管理后台系统 - 启动指南

## 📋 环境要求

### 后端环境
- ✅ **JDK 1.8+**（已检测：1.8.0_121）
- ⚠️ **Maven 3.6+**（需要自行安装配置）

### 前端环境
- ✅ **Node.js 14+**（已检测：24.15.0）
- ✅ **NPM**（已检测：11.12.1）

## 🚀 后端启动方式

### 方式一：使用Maven命令（推荐）
```bash
# 进入后端目录
cd backend

# 1. 编译项目
mvn clean compile -DskipTests

# 2. 运行项目
mvn spring-boot:run
```

### 方式二：使用IDE运行
1. 使用IDEA/Eclipse打开`backend`目录
2. 等待Maven依赖下载完成
3. 找到`PetClinicApplication.java`，右键运行

### 方式三：打包后运行
```bash
# 打包
mvn clean package -DskipTests

# 运行jar包
java -jar target/pet-clinic-backend-1.0.0.jar
```

## 🎨 前端启动方式

## 🔧 常见问题

### Q1: Maven命令找不到怎么办？
**A:** 请先安装Maven并配置环境变量：
1. 下载Maven：https://maven.apache.org/download.cgi
2. 解压到本地目录
3. 配置`MAVEN_HOME`环境变量
4. 将`%MAVEN_HOME%\bin`添加到PATH
5. 验证：`mvn -version`

### Q2: 前端npm install速度慢？
**A:** 可以使用淘宝镜像：
```bash
npm config set registry https://registry.npmmirror.com
```

### Q3: 后端启动端口被占用？
**A:** 修改`backend/src/main/resources/application.properties`：
```properties
server.port=8081  # 改成其他端口
```

### Q4: 数据库数据想重置？
**A:** 删除`backend/data`目录，重启服务即可重新初始化。
