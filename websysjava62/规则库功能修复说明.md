# 规则库内容审核与阻止功能修复说明

## 🔧 修复内容概述

**问题**：原系统的规则库仅包含敏感词的简单检查功能，但缺乏对违规产品及内容的实际过滤和阻止功能。

**解决方案**：实现了完整的内容审核体系，包括：
- ✅ 内容审核服务（检测、过滤、替换）
- ✅ AOP自动拦截审核
- ✅ 违规内容阻止机制
- ✅ 详细的审核结果返回
- ✅ 敏感词动态管理

## 🚀 核心功能实现

### 1. 审核级别机制

系统实现了三级违规检测：

| 级别 | 触发条件 | 处理方式 |
|-----|---------|---------|
| **HIGH（高级）** | 检测到5个以上敏感词 | 阻止操作，抛出异常 |
| **MEDIUM（中级）** | 检测到2-4个敏感词 | 阻止操作，抛出异常 |
| **LOW（低级）** | 检测到1个敏感词 | 自动过滤替换，允许操作 |

### 2. 敏感词替换功能

检测到敏感词后自动替换为等长度的`*`号，例如：
- 原始内容：`这是一个违禁内容`
- 过滤后内容：`这是一个**内容`

### 3. AOP自动审核机制

通过`@NeedReview`注解，实现：
- 自动拦截方法参数
- 收集所有字符串类型字段
- 执行内容审核
- 低级违规自动更新参数字段值
- 中高级违规阻止操作并抛出异常

### 审核规则相关

| 接口 | 方法 | 功能说明 |
|-----|------|---------|
| `/api/review-rules/review` | POST | 完整内容审核，返回详细结果 |

## 💡 使用方式

### 1. 对方法启用自动审核

在需要审核的Controller方法上添加`@NeedReview`注解：

```java
@PostMapping
@NeedReview
public Result<Medicine> saveMedicine(@RequestBody Medicine medicine) {
    // 方法体...
}
```

### 2. 手动调用审核服务

```java
@Autowired
private ReviewRuleService reviewRuleService;

// 完整审核
ReviewResult result = reviewRuleService.reviewContent(content);

// 审核并阻止
ReviewResult blocked = reviewRuleService.reviewAndBlock(content);
if (blocked != null) {
    // 阻止操作
}
```

### 3. 管理敏感词

```java
// 添加敏感词
reviewRuleService.addSensitiveWord(ruleId, "敏感词");

// 移除敏感词
reviewRuleService.removeSensitiveWord(ruleId, "敏感词");

// 获取所有启用的敏感词
Set<String> words = reviewRuleService.getAllEnabledSensitiveWords();
```

- 缓存有效期：5分钟
- 修改规则时自动清除缓存
- 提供手动清除缓存API

## 🎯 审核字段范围

AOP切面自动审核以下字段：
