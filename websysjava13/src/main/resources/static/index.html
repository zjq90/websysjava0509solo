系统介绍

本系统是一个集成移动端H5看板的Web平台管理系统，主要功能包括：

  • 移动端H5看板集成：管理层可通过移动端实时查看经营动态
  • 灵活的配置功能：可配置默认显示项，也可自由配置显示项
  • 统计项管理：增删改查各类统计指标
  • 经营数据管理：维护各类经营数据
  • 测试辅助功能：一键生成测试数据，方便功能测试
