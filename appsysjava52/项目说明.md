# 文物收藏管理系统 - 项目说明

## 项目概述

这是一个专业的文物收藏管理系统，采用前后端分离架构，提供完整的文物收藏、鉴定、溯源、环境监测等功能。

## 技术栈

### 后端技术
- **框架**: Spring Boot 2.7.18
- **数据库**: H2 (内存数据库，无需额外安装)
- **缓存**: Redis (模拟实现，可配置真实Redis)
- **API文档**: Swagger/OpenAPI 3.0
- **ORM**: Spring Data JPA
- **安全**: RSA加密、JWT认证

### 前端技术
- **框架**: UniApp (Vue 3)
- **样式**: SCSS
- **功能**: 响应式设计、长辈模式、RSA加密

## 核心功能

### 1. 文物展示模块
- 文物列表浏览（8个示例文物）
- 分类筛选和搜索
- 文物详情页
- 3D模型加载标识
- 全景展示标识
- 高清图片放大镜

### 2. 鉴定服务模块
- 在线提交鉴定申请
- 照片/视频上传
- 专家匹配
- 鉴定报告生成
- 鉴定进度跟踪

### 3. 溯源查询模块
- 区块链验证标识
- 拍卖记录查询
- 历史交易追踪
- 真伪验证记录

### 4. 收藏管理模块
- 个人收藏库
- 收藏详情展示
- 环境监测数据
- 24小时温湿度趋势图
- 异常值检测警告
- 保养提醒系统
- 权威文献参考

### 5. 长辈模式
- 字体放大（可配置）
- 按钮尺寸增大
- 简化界面布局
- 语音输入支持（模拟）
- 分步引导操作
- 高对比度配色（可配置）

### 6. 安全功能
- RSA加密敏感数据
- 公钥动态获取
- 自动加密敏感字段
- 密码安全存储（BCrypt）

## 快速开始

### 环境要求
- JDK 8 或更高版本
- Maven 3.6 或更高版本
- Node.js 14+ (前端开发可选)
- HBuilderX (前端开发推荐)

### 后端启动

#### 方式1：使用启动脚本（Windows）
```bash
# 双击运行或在命令行执行
start.bat
```

#### 方式2：手动启动
```bash
cd backend
mvn spring-boot:run
```

#### 后端访问地址
- **应用接口**: http://localhost:8080/api
- **Swagger文档**: http://localhost:8080/api/swagger-ui.html
- **H2数据库控制台**: http://localhost:8080/api/h2-console
  - JDBC URL: `jdbc:h2:mem:heritage_db`
  - 用户名: `sa`
  - 密码: (空)

### 前端启动

#### HBuilderX方式（推荐）
1. 使用HBuilderX打开`frontend`目录
2. 点击"运行" -> "运行到浏览器" -> "Chrome"
3. 或选择"运行到小程序模拟器"

#### 命令行方式
```bash
cd frontend
npm install
npm run dev:h5
```

## API接口说明

### 公共接口
- `GET /api/common/public-key` - 获取RSA公钥
- `GET /api/common/health` - 健康检查
- `POST /api/common/encrypt-test` - 加密测试
- `POST /api/common/decrypt-test` - 解密测试

### 文物接口
- `GET /api/heritage/list` - 文物列表
- `GET /api/heritage/{id}` - 文物详情
- `GET /api/heritage/{id}/trace` - 溯源记录

### 鉴定接口
- `GET /api/auth/list` - 鉴定申请列表
- `POST /api/auth/submit` - 提交鉴定申请
- `GET /api/auth/{id}` - 申请详情

### 收藏接口
- `GET /api/collection/list` - 收藏列表
- `GET /api/collection/{id}` - 收藏详情
- `GET /api/collection/{id}/environment` - 环境数据
- `GET /api/collection/{id}/maintenance` - 保养提醒

### Swagger文档
启动后端后访问 http://localhost:8080/api/swagger-ui.html 可查看完整的API文档和在线测试功能。

## 长辈模式使用

1. 登录后进入"我的"页面
2. 找到"长辈模式"开关
3. 开启后界面会自动调整：
   - 字体放大约30%
   - 按钮尺寸增大
   - 复杂元素隐藏
   - 操作流程简化

可在`frontend/utils/elderMode.js`中自定义长辈模式配置。

## RSA加密说明

### 后端
- 启动时自动生成RSA密钥对（2048位）
- 提供公钥获取接口
- 敏感字段自动解密
- 支持分段加密长文本

### 前端
- 自动从后端获取公钥
- 敏感字段（密码、手机号、身份证等）自动加密
- 加密失败时有降级方案（Base64编码）
- 可在`frontend/utils/rsa.js`中配置

## 功能特色

1. **模块化设计**: 清晰的分层架构，易于扩展
2. **自动测试数据**: 启动时自动生成丰富的测试数据
3. **Swagger文档**: 完整的API文档和在线测试
4. **长辈模式**: 专为老年用户优化的界面
5. **RSA加密**: 端到端的敏感数据保护
6. **响应式设计**: 适配多种屏幕尺寸
7. **环境监测**: 实时温湿度监控和异常警告
8. **专业保养**: 基于权威文献的保养建议

## 注意事项

1. **H2数据库**: 内存数据库，重启后数据丢失，生产环境建议改用MySQL
2. **Redis**: 当前为模拟实现，生产环境需配置真实Redis
3. **RSA密钥**: 启动时自动生成，生产环境建议配置固定密钥
4. **前端3D模型**: 示例代码仅显示标识，实际使用需集成3D渲染库
5. **长辈模式语音**: 模拟实现，实际使用需集成语音识别SDK
