# 花店APP系统 - 问题修复说明

## 已修复的问题

### 1. 前端npm依赖版本问题

**问题描述**：
```
npm error notarget No matching version found for @dcloudio/uni-app@3.0.0-alpha-4020420240930001
```

**修复方案**：
- 更新了 `frontend/package.json` 中的依赖版本为稳定版 `3.0.0-4020920250520001`
- 移除了不必要的平台依赖，只保留核心依赖
- 创建了 `frontend/README.md` 详细说明安装方法

**推荐安装方式**：
1. 使用HBuilderX（推荐）
2. 使用更新后的npm依赖配置

### 2. 后端H2数据库问题

**问题1：表找不到**
```
org.h2.jdbc.JdbcSQLSyntaxErrorException: Table "COUPON" not found
```

**问题2：SQL关键字冲突**
```
Syntax error in SQL statement ... value DECIMAL(10,2) ... expected "identifier"
```
`value` 是SQL保留关键字，不能直接用作列名。

**修复方案**：

#### 2.1 修复列名冲突
- **Coupon实体**：`value` 字段添加 `@Column(name = "discount_value")` 注解
- SQL脚本中对应列名改为 `discount_value`

#### 2.2 修复表名不一致
- **Order实体**：`@Table(name = "orders")` → `@Table(name = "sys_order")`

#### 2.3 简化数据库配置
使用JPA自动建表，移除SQL脚本初始化，避免重复执行问题：
```yaml
spring:
  datasource:
    url: jdbc:h2:mem:flower_shop;DB_CLOSE_DELAY=-1
  jpa:
    hibernate:
      ddl-auto: create-drop  # 启动时创建，关闭时删除
```

### 3. 修复API路径配置

**问题**：前端请求路径重复/api

**修复**：
- `frontend/utils/request.js` 中 `baseUrl` 从 `/api` 改为 `http://localhost:8080/api`

### 4. 之前已修复的编译问题（已在之前修复）

#### 4.1 Result类双参数success方法
- 文件：`backend/src/main/java/com/flower/common/Result.java`
- 新增：`Result.success(String message, T data)

#### 4.2 Java 8兼容性
- 文件：`backend/src/main/java/com/flower/service/UserService.java`

#### 4.3 Repository方法名

- 文件：`backend/src/main/java/com/flower/repository/PickupPointRepository.java`
- `findByEnabledTrue()` → `findByEnabled(Boolean enabled)`

- 文件：`backend/src/main/java/com/flower/service/ActivityService.java`
- 同步更新service层调用

## 启动说明

### 后端启动
1. 确保JDK 8+环境
2. 进入backend目录
3. 运行：`mvn spring-boot:run`
4. 访问：
   - API地址：http://localhost:8080/api
   - H2控制台：http://localhost:8080/api/h2-console
   - Swagger文档：http://localhost:8080/api/swagger-ui.html

### 前端启动
1. **推荐方式**：使用HBuilderX打开frontend目录
2. 运行到浏览器或模拟器

1. **Redis为可选依赖，如未安装Redis，缓存功能会自动降级

4. 生产环境建议更换为MySQL等持久化数据库
