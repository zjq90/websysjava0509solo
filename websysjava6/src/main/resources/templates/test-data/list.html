设备数据推送接口：
POST /api/equipment/{设备编号}/data
Content-Type: application/json

{
    "runStatus": "RUNNING",
    "currentSpeed": 120.5,
    "productionOutput": 500,
    "runDuration": 120,
    "temperature": 45.2,
    "pressure": 0.3,
    "alarmMessage": ""
}
获取设备状态：
GET /api/equipment/{设备ID}/status
获取设备历史数据：
GET /api/equipment/{设备ID}/history?start=开始时间&end=结束时间
