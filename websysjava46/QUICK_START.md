# 🚀 快速启动验证指南

## 一、启动后端服务

### 1. 使用IDE启动
- 打开后端项目
- 运行 `FlowerShopApplication.java` 主类
- 观察控制台输出，确认无异常

### 2. 验证后端启动

访问以下地址验证后端是否正常：

| 服务 | 地址 | 预期结果 |
|------|------|----------|
| 健康检查 | http://localhost:8080/api/system/health | 返回JSON包含 `status: "UP"` |
| Swagger API文档 | http://localhost:8080/swagger-ui/index.html | 显示API文档界面 |
| H2数据库控制台 | http://localhost:8080/h2-console | 显示H2登录页面 |

**H2数据库连接信息：**
- JDBC URL: `jdbc:h2:mem:flower_shop`
- 用户名: `sa`
- 密码: (空)

## 二、启动前端服务

### 1. 安装依赖
```bash
cd frontend
npm install
```

### 2. 启动开发服务器
```bash
npm run serve
```

### 3. 验证前端启动

启动成功后访问：
- **管理系统：** http://localhost:8081

预期显示：
- 左侧导航菜单（6个功能模块）
- 顶部显示当前页面标题
- 默认显示"数据看板"页面

## 三、常见问题排查

### 问题1：后端启动失败
**症状：** 控制台报错，服务无法启动

**排查：**
1. 检查端口8080是否被占用
2. 检查Maven依赖是否下载完整
3. 查看控制台具体错误信息

### 问题2：Swagger页面空白
**症状：** 访问swagger-ui页面显示空白

**排查：**
1. 确认已访问正确路径：`/swagger-ui/index.html`
2. 清除浏览器缓存后重试
3. 检查浏览器控制台是否有404错误

### 问题3：前端页面空白
**症状：** 浏览器显示空白页面

**排查：**
1. 打开浏览器F12控制台，查看是否有JavaScript错误
2. 确认所有 `.vue` 文件语法正确，有完整的 `<template>` 闭合标签
3. 检查是否安装了所有依赖：`npm install`
4. 重启开发服务器

### 问题4：API请求失败
**症状：** 前端提示"网络请求失败"

**排查：**
1. 确认后端服务已启动并运行在8080端口
2. 访问健康检查接口验证后端
3. 检查浏览器Network标签，查看请求详情
4. 确认跨域配置CorsConfig已生效
