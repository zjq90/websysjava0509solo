测试流程建议
进销存与财务联动测试
  1. 创建一个新的销售订单（状态为待审核）
  2. 查看订单详情，确认尚未生成财务账款
  3. 点击"确认订单"按钮
  4. 查看财务管理，确认自动生成了应收账款
  5. 对该账款进行收款操作
  6. 验证账款状态变化为部分结清/已结清
成本与利润分析测试
  1. 在成本核算中录入各类成本记录
  2. 按品种/区域关联成本记录
  3. 进入利润分析模块
  4. 查看按品种、客户、区域的利润分析
  5. 验证利润计算是否正确（销售-成本）
