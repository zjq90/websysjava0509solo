# 前端依赖安装说明

## 问题说明

HBuilderX 运行时提示 `uview-plus` 依赖未安装，需要手动执行 npm install。

## 解决方案

### 方案一：使用 HBuilderX 自动安装（推荐）

1. 在 HBuilderX 中，右键点击项目根目录（frontend文件夹）
2. 选择「使用 npm 安装」
3. 等待安装完成即可

### 方案二：使用命令行安装

1. 打开命令行工具（CMD 或 PowerShell）
2. 进入前端项目目录：
   ```bash
   cd d:\Aijava\javaproject\260509\solocodeJava\v74\appsysjava74\frontend
   ```
3. 执行安装命令：
   ```bash
   npm install
   ```
4. 等待安装完成后，重新运行项目

### 方案三：单独安装 uview-plus

如果只缺少 uview-plus 依赖，可以单独安装：

```bash
cd frontend
npm install uview-plus@3.2.15
```

## 验证安装

安装完成后，检查 `frontend` 目录下是否存在 `node_modules` 文件夹，并且里面有 `uview-plus` 目录。

## 常见问题

### 1. npm install 速度慢

可以使用淘宝镜像：
```bash
npm config set registry https://registry.npmmirror.com
npm install
```

### 2. 安装失败

删除 `node_modules` 文件夹和 `package-lock.json` 文件后重新安装：
```bash
rmdir /s /q node_modules
del package-lock.json
npm install
```

### 3. 安装后仍然报错

1. 关闭 HBuilderX
2. 删除项目下的 `unpackage` 文件夹
3. 重新打开 HBuilderX 并运行项目
