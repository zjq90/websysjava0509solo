测试数据生成流程说明
  1. 基础数据：先生成供应商、客户、产品数据
  2. 采购入库：生成采购单，增加库存数量
  3. 销售出库：生成销售单，减少库存数量
  4. 查看报表：进入数据统计模块查看销售报表、库存周转率、毛利率分析、需求预测
